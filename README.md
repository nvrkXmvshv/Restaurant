## 🍽️ **Ресторан — сайт для знакомства с заведением и планирования визита:** позволяет изучить акции и фотографии, найти контакты и местоположение, забронировать столик, а также удобно отфильтровать меню по типам блюд.

---

## Техническое задание

Разрабатываемый веб-интерфейс обеспечивает выполнение следующих обязательных функций:

1. Отображение информации о ресторане, включая описание, акции, банкетные услуги и контактные данные.
2. Просмотр меню ресторана с разделением блюд по категориям.
3. Возможность оформления бронирования столиков через специальную форму.
4. Проверку корректности пользовательских данных при заполнении формы бронирования.
5. Корректное отображение интерфейса на различных устройствах и разрешениях экрана.

### Дополнительно реализованные требования (желательные)

1. Реализация переключения между светлой и тёмной темой оформления.
2. Сохранение выбранной темы пользователя с использованием `localStorage`.
3. Добавление анимаций и плавных переходов для улучшения пользовательского интерфейса.
4. Реализация слайдера акций с автоматической сменой элементов.
5. Использование модульной структуры JavaScript-кода с разделением функциональности по отдельным файлам.

---

## 🛠 Технологии

- **HTML5** – семантическая разметка
- **CSS3** – Flexbox, Grid, медиа-запросы, CSS-переменные (для тем)
- **JavaScript ES6+** – модульная архитектура (import/export), работа с DOM, `localStorage`
- **GitHub Pages** – хостинг
